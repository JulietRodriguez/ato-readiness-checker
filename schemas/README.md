# NIST OSCAL 1.1.2 JSON schemas

Unmodified copies of four schemas from the
[OSCAL v1.1.2 release](https://github.com/usnistgov/OSCAL/releases/tag/v1.1.2):
SSP, Assessment Results, POA&M and profile. They are kept here so the tests run
offline. CI downloads the same files from the release and checks them against
`SHA256SUMS`, so these copies can't drift from NIST's.
